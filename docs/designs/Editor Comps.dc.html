Why this works
  • Zero chrome by default. The toolbar isn’t stripped away — it just lives behind one key, so a blank page stays blank.
  • Every row teaches. Icon, name, and a one-line description, plus the markdown shortcut on the right for people who’d rather type it.

The rules
  • Only the six you reach for. Bold, italic, link, highlight, inline code, and turn-into (H2 / quote / list). Nothing rarely-used clutters the bar.
  • Tooltips do the teaching. Label, plain-language description, and the keyboard shortcut — so people graduate to shortcuts on their own.
  • It disappears. Deselect and the bar is gone. The reading experience is never crowded by editing chrome.

Handling complexity
  • Contextual, not global. Image controls belong to the image — they appear on the block, not in a distant top toolbar you have to connect mentally.
  • Gentle nudges, not blockers. Missing alt text prompts a soft, dismissible note — it never stops you from publishing.
  • Same grammar everywhere. Embeds, code, and callouts use the identical hover-bar pattern, so one block teaches them all.

The split
  • Writing vs. shipping. The canvas is only for words and blocks. Every decision about the post — who sees it, where it lives — waits in the drawer.

Reeling In the Right Gear

A rod, a reel, and a small box of the right terminal tackle will out-fish an expensive setup nine times out of ten. The trick was never the money — it was learning what each piece is for, and leaving the rest at home.

Start with the rod. A medium-power, fast-action spinning rod around seven feet covers almost everything a beginner will meet: panfish off a dock, bass in the weeds, the occasional hopeful cast for something larger.

Why rename
  • “View” is developer-speak. To a writer it means nothing. Collection — a curated set of posts — matches what they’re actually making. (Feeds / Lists work too.)
  • Each card shows its shape. A mini render, the plain-language rule (“by tag · newest first”), and the copy-ready embed token — no need to open it to remember what it does.
  • Empty state stays. Your calm “Nothing here yet” welcome is kept for a first-time list.

Untangling new & edit
  • Words, not a query language. The old screen opened on SQL and a JS function — a wall for most writers. Now you describe the result and AI writes both.
  • The code isn’t gone. It’s generated, labelled, and editable in the Advanced panel — power users keep full control, beginners never have to look.
  • Less chrome to fight. The full sidebar collapses to a “← Collections” breadcrumb, so creating one is a calm, focused task — not a form buried in nav.
  • New and Edit are one screen. Same layout either way — nothing new to learn to change an existing collection.

The whole idea, in four lines
01
Blank by default.
A new page is a title and a cursor. No toolbar wall to decode before you can write a sentence.
02
Power on demand.
Every function is one keystroke, hover, or drawer away — present the instant you reach for it, gone when you don’t.
03
Everything explains itself.
Rich tooltips and a three-step first-run tour teach the tools in place — no manual, no guessing.
04
Complexity, contained.
Media and layout controls live on the block itself, using one repeated pattern so a single lesson covers them all.
